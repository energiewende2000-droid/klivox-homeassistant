# Klivox-Brücke

Verbindet Geräte in deinem Heimnetz, die nur lokal erreichbar sind – zum Beispiel den **Bosch Smart Home Controller** – mit der Klivox Cloud. Die Brücke baut nur ausgehende Verbindungen auf; am Router muss nichts freigegeben werden.

## Einrichten

1. In Klivox unter **Geräte › Klivox-Brücke** auf **Kopplungscode erzeugen** tippen.
2. Hier im Add-on unter **Konfiguration** den Code bei `kopplungscode` eintragen und speichern.
3. Add-on **starten**. Im Protokoll erscheint „Gekoppelt“, in Klivox steht die Brücke auf **Online**.
4. Bosch koppeln: in Klivox das Systempasswort eintragen, die Taste am Controller drücken, bis die Leuchten blinken, dann **Koppeln** tippen.

Der Code ist 30 Minuten gültig. Für eine neue Kopplung einfach einen neuen Code eintragen und das Add-on neu starten.
