# Klivox für Home Assistant

Add-on-Repository für Home Assistant.

**Einbinden:** Einstellungen › Add-ons › Add-on-Store › ⋮ (oben rechts) › Repositories › diese Adresse eintragen:

```
https://github.com/energiewende2000-droid/klivox-homeassistant
```

Danach **Klivox-Brücke** installieren. Anleitung im Add-on unter „Dokumentation“.
